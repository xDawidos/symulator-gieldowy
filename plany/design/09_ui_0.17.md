# Projekt UI 0.17: giełda towarowa, fracht, bezpieczeństwo, ustawa, autostrada

Data: 2026-11-04 · zlecenia: `plany/plan_0.17_surowce_transport.md`, `plany/plan_0.17_specyfikacja.md` · system: [03_system.md](03_system.md) · makieta z prawdziwymi klasami: [makiety/09_ui_017.html](makiety/09_ui_017.html) · stan prac: [08_zaleglosci_0.16_0.17.md](08_zaleglosci_0.16_0.17.md).

To projekt dla czatu kodu. Klasy CSS i ikony są już w grze (blok „0.17” na końcu `style.css`, `UI_ICON_PATHS` w `ui.js`, eksport w `img/ikony/`). Figma nie była używana (serwer nie łączył się przy starcie); źródłem jest makieta.

## Zasady
1. **Kolor nigdy sam.** Krzywa = strzałka + słowo. Kierunek = ▲▼■ + liczba. Stan depozytu = ikona + liczba + słowo + miernik.
2. **Bez nowych okien.** Wszystko w zakładce Kantora, oknie „Rynek”, karcie kraju, Państwie i oknie przetargu.
3. **Bez nowych tokenów.** Jeden wzór pola (`.fx-form`), jeden wzór stanu depozytu (`.fx-cover`), oś kroków z sekcji Kryzys (`.crisis-axis`), pasek `.limit-meter` z 0.15.5.
4. **Ikony po identyfikatorach:** `uiIcon(`surowiec-${id}`)`, `uiIcon(`transport-${id}`)`, `uiIcon('umiejetnosc-opcje')`. W `<option>`, `title` i `aria-label` sam tekst.

## Dostępność
Paski mają `role="img"` i `aria-label`, wartość zawsze też tekstem. Wiersze listy surowców działają z Enter (jak u S7). Na ≤ 640 px `.law-steps` i `.hw-strip` idą w kolumnę, tabele Kantora przewijają się w poziomie.
